# Nightfall: The Last Signal

An original, asset-free Godot 4 asymmetric survival-horror game prototype. It uses procedural graphics and original names rather than assets, characters, maps, or branding from any existing game.

## Run

1. Import this folder into Godot 4.3 or newer.
2. Press `F6` / Run Project.

## Controls

- **Survivor:** `WASD` to move, hold `E` beside a relay to restore it, then hold `E` at the open exit.
- **Warden:** `WASD` to move, hold `E` to sprint, `Space` to strike.
- `Esc` returns to the title screen.

Choose either role from the title screen. The opposing role is AI-controlled.
